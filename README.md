# Project Outpost

Third-person survival crafting game with worker automation. Built in Godot 4.7 (GDScript).

Open `project.godot` in Godot and press F5 (Run Project). See `docs/ROADMAP.md` for the plan.

## Controls
| Action | Keyboard / Mouse | Gamepad |
|---|---|---|
| Move | WASD | Left stick |
| Look | Mouse | Right stick |
| Sprint (hold) | Shift | Left stick click |
| Jump | Space | A / Cross |
| Zoom | Scroll wheel | D-pad up / down |
| Free / grab mouse | Esc (click to grab again) | Start |
